# Dados

Os dados dos quatro desafios. Use a pasta do seu; cada uma tem um `LEIAME.md` com o que é cada arquivo e
como calcular os indicadores.

| Pasta | Desafio |
| --- | --- |
| `desafio-1-treinamento/` | Treinamento que ensina a vender |
| `desafio-2-dashboards/` | O número certo, onde a pessoa já está |
| `desafio-3-feedback/` | O feedback que ninguém dá |
| `desafio-4-orquestracao/` | O treinamento certo, na hora certa |

São dados fictícios da Rede Aurora: nenhuma pessoa, loja, telefone, produto ou venda é real.
Os CSV usam vírgula como separador, ponto como separador decimal e UTF-8. No Excel, abra por
Dados > De Texto/CSV.
