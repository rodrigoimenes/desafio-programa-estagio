# Prompts

O histórico de como você usou IA.

- `claude-code/`: preenchida sozinha pelo Claude Code, um arquivo por dia.
- `<ferramenta>/`: o que Cursor, Copilot ou Codex registrarem seguindo o `AGENTS.md`.
- `chats.md`: conversas de chats (ChatGPT, Claude.ai, Gemini…), exportadas ou como link de compartilhamento.

Faça commit destes arquivos junto com o trabalho a que eles se referem.
